# PASCAL LM : Le LLM 100% Bitwise (HDC-AR)

**Pascal LM** est une exploration radicale de l'intelligence artificielle frugale. Contrairement aux modèles classiques basés sur des trillions de paramètres flottants et des clusters de GPUs, Pascal LM repose sur le **Calcul Hyperdimensionnel (HDC)** et l'arithmétique binaire pure.

> "Zéro GPU. Zéro Flottant. Inscription locale totale."

## 🧠 Architecture : HDC-AR
Pascal LM utilise une architecture autorégressive hybride :
- **Contexte Local** : Rotations XOR sur n-grammes (Précision syntaxique).
- **Contexte Global** : Accumulateur sémantique à decay (Cohérence thématique).
- **Reasoning Milestone (Phase 3B)** : Intégration d'un **Binary Transformer** différentiable via STE (Straight-Through Estimator).

Technique

ARCHITECTURE HDC-AR

Deux contextes. Un consensus binaire. Une mémoire darwinienne.

# Pascal LM — Flux d'inférence

INPUT → tokenize(text)
         ↓
LOCAL  = XOR( T[n] ⊕ rot(T[n-1],1)
                     ⊕ rot(T[n-2],2) ... )
         ↓
GLOBAL = accumulate(
               G = G * 0.95 + T[n]
               )
         ↓
# Backoff Search (exact match)
 SQLite → n-gram order 5→4→3→2
         ↓ (no match)
# Thematic Fallback
 QUERY  = LOCAL XOR GLOBAL
         → 8-head binary attention
         → majority vote
         ↓
OUTPUT → next_token + accumulate
01

CONTEXTE LOCAL — Syntaxe

Fenêtre glissante de 5 tokens encodée par rotations XOR. Capture les structures syntaxiques immédiates avec une précision chirurgicale.

02

CONTEXTE GLOBAL — Thème

L'accumulateur cumule la "mémoire sémantique" de toute la séquence avec un decay de 0.95. La cohérence thématique sur 100+ tokens.

03

BACKOFF MULTI-ÉCHELLE

Recherche pondérée sur les ordres 5→4→3→2. Score = count × n³. Si aucun match, fusion des deux contextes via 8 têtes d'attention binaire.

04

MÉMOIRE DARWINIENNE

Chaque souvenir possède un score de "hits". Les moins utiles sont écrasés. Le modèle évolue vers ce qui compte vraiment.
